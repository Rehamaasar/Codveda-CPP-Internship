# Codveda C++ Internship

This repository contains the tasks I completed as part of my **C++ Development Internship at Codveda Technologies**.

The internship tasks are organized into three levels, progressing from fundamental C++ programming concepts to algorithms, file handling, and multithreading.

## 📂 Project Structure

### Level 1 — C++ Fundamentals

#### Task 1: Basic Calculator
A console-based calculator that performs basic arithmetic operations.

**Concepts used:**
- Variables and data types
- User input/output
- Conditional statements
- Arithmetic operations

#### Task 3: String Manipulation
A program that performs multiple operations on user-provided strings.

**Features:**
- Reverse a string
- Count vowels
- Check whether a string is a palindrome

**Concepts used:**
- Strings
- Loops
- Conditional statements
- Character manipulation

---

### Level 2 — Data Structures & Algorithms

#### Task 1: Student Management System
A console-based system for storing and managing student information.

**Features:**
- Store student ID, name, and grade
- Display student information
- Calculate the average grade
- Search for a student by ID
- Find the student with the highest grade

**Concepts used:**
- Structures
- Vectors
- Loops
- Searching
- Data management

#### Task 2: Sorting and Searching Algorithms
A program demonstrating fundamental sorting and searching techniques.

**Algorithms implemented:**
- Bubble Sort
- Binary Search

**Concepts used:**
- Vectors
- Nested loops
- Sorting algorithms
- Searching algorithms

---

### Level 3 — Advanced C++

#### Task 1: File System Simulation
A console application that demonstrates basic file-management operations.

**Features:**
- Create a file
- Write data to a file
- Read file contents
- Delete a file

**Concepts used:**
- File handling
- `ifstream`
- `ofstream`
- User-driven menus

#### Task 2: Multithreaded Application
A C++ application demonstrating concurrent execution using multiple threads.

**Concepts used:**
- `std::thread`
- Multithreading
- Mutexes
- Thread synchronization
- `join()`
